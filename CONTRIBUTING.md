# Contributing to Krypto Kenya Rise

Thanks for wanting to contribute! Please follow these steps:

1. Fork the repo and create a branch: `git checkout -b feat/my-feature`
2. Follow the coding style used in the repo.
3. Add tests for new functionality.
4. Run the test suite: `npm test`
5. Open a pull request describing what you changed and why.

We use the "squash and merge" workflow. Please write a descriptive commit message and reference any related issue.
