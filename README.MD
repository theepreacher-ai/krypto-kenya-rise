Quick start
-----------
1. Clone
   ```bash
   git clone https://github.com/theepreacher-ai/krypto-kenya-rise.git
   ```
2. Install
   ```bash
   cd krypto-kenya-rise
   npm install
   ```
3. Run
   ```bash
   npm start
   ```

Tests
-----

Run the test suite:
```bash
npm test
```
